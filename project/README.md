### Description:
My project is about a simple calculator which accepts two numbers and performs below arithmetic operations:
1. Addition
2. Subtraction
3. Multiplication
4. Division

User is presented with a menu consisting of these 4 operations and a fifth one to exit the program. If the user does not select appropriate numerical response, he/she is presented again the menu option. In case, the user enters alphabetical characters while choosing the menu, the program exits with message Invalid option.

**add():** Function `add()` prompts user to enter first number and then second number, add them and finally prints the result in below format:
`3.0 + 4.0 = 7.0`
where 3 is the first number entered by the user and 4 is the second number entered.

**subtract():** Function `subtract()` prompts user to enter first number and then second number, subtract the second number from first number and finally prints the result in below format:
`4.0 - 3.0 = 1.0`
where 4 is the first number entered by the user and 3 is the second number entered.

**multiply():** Function `multiply()` prompts user to enter first number, then second number, multiplies them and finally prints the result in below format:
`4.0 * 3.0 = 12.0`

**divide():** Function `divide()` prompts user to enter first number, then second number, divides the first number by second number and then finally prints the result in below format:
`4 / 2 = 2.0`

In case, the second number entered is 0, the program prints an error message "Division by 0 not supported" and prints the menu again.

Additionally, it handles the scenario in division when the user tries to divide a number by zero.
